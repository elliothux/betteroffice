New `@betteroffice/docx-native`, `@betteroffice/xlsx-native` and `@betteroffice/pptx-native` packages run the Rust engines as prebuilt Node.js and Bun binaries: open, edit, render PNGs and save `Buffer`s without WebAssembly or a browser.
